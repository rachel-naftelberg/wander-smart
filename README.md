# 🧭 WanderSmart • Vienna Travel Companion 🇦🇹

אפליקציית תכנון טיול וליווי חכם בשטח לוינה, בהשראת **Wanderlog** עם מפה אינטראקטיבית, זמני הגעה חיים, יבוא קבצים, והתאמה חכמה למזג אוויר ואירועים.

## ✨ תכונות מרכזיות (Features)

1. **🎨 ממשק עשיר בעיצוב Wanderlog**:
   - כרטיסי יעדים נקיים ומודרניים בגווני קורל (`#ff5a5f`), רקעים לבנים וטיפוגרפיה ברורה.
   - מפת **Leaflet** אינטראקטיבית עם סימוני מספור תואמים למסלול, קווי נסיעה, וסימון יעד המלון בסגול.

2. **🧭 כפתור נווט ב-Google Maps ישירות מכל כרטיס**:
   - כפתור ניווט בולט וראשי הפותח מסלול ניווט חי בטלפון או במחשב בלחיצה אחת.

3. **📅 העברה מהירה בין ימים (1-Click Day Transfer)**:
   - כפתורי העברה ישירה `[יום 1] [יום 2] [יום 3] [יום 4] [יום 5]` על גבי כל כרטיס, עם מעבר תצוגה מיידי ואנימציית הדגשה (`highlight-pulse`).

4. **🕒 קביעה ידנית של שעת התחלת היום**:
   - בורר שעת יציאה מהמלון לכל יום בנפרד עם חישוב אוטומטי מחדש של כל לוחות הזמנים ושעות ההגעה.

5. **🔍 חיפוש חכם ואישור מועמדים לפני הוספה**:
   - חיפוש עם פרטים מאומתים: שעות פתיחה, מחירי כרטיסים, האם האתר מקורה (מותאם לגשם), וזמן ביקור ממוצע.
   - **אירועים והופעות מיוחדות באתר**: קונצרט עוגב הענק בסנט סטפן, ארבע העונות של ויוואלדי בכנסיית קרל, קונצרט מוצרט בשונברון, סוסי ליפיצן בהופבורג ועוד.
   - כפתור שמירה ישירה של מופעים ללוח האירועים האישי.

6. **📍 זיהוי מיקום GPS והמשך טיול אוטומטי**:
   - זיהוי תאריך ומיקום המשתמשת בשטח, חישוב המרחק ליעד הקרוב שטרם בוצע, וגלילה אוטומטית ליעד הבא.

7. **📂 יבוא תוכניות מרובות פורמטים (PDF / Excel / Text)**:
   - מפענח מובנה לקובצי PDF (באמצעות PDF.js), גיליונות אקסל ו-CSV (באמצעות SheetJS), וטקסט חופשי עם תמיכה בעברית ויזואלית הפוכה.

8. **💳 יועץ כרטיסים וחיסכון (Pass Optimizer)**:
   - השוואת מחירים בזמן אמת בין כרטיסים בודדים בקופות, Vienna Pass, ו-Vienna City Card.

9. **☔ ארגון יום חכם לגשם (Rain Reorganizer)**:
   - הקדמת מוזיאונים ואתרים מקורים לשעות בהן צפוי גשם בלחיצת כפתור אחת.

10. **🖨️ הדפסה ושיתוף**:
    - אפשרות להדפסת תוכנית יומית נקייה לנייר ושיתוף מהיר לוואטסאפ או ללוח ההעתקה.

## 🚀 איך מריצים את הפרויקט? (How to Run)

### אפשרות 1: בלחיצה כפולה (Windows)
- לחצי פעמיים על הקובץ **`start_app.bat`**.
- הדפדפן ייפתח אוטומטית בכתובת: `http://localhost:3000`.

### אפשרות 2: משורת הפקודה (Node.js)
```bash
# הרצת השרת המקומי
node server.js
```
פתחי את הדפדפן בכתובת: [http://localhost:3000](http://localhost:3000)

## 🛠️ טכנולוגיות (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS3 (CSS Variables, Flexbox, CSS Grid), Vanilla JavaScript ES6+.
- **Maps**: Leaflet.js & OpenStreetMap.
- **Parsing**: SheetJS (XLSX), Mozilla PDF.js.
- **Backend / Server**: Node.js HTTP Server (ללא תלויות חיצוניות כבדות).
